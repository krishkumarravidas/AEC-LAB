Geometric Distribution

First success model

X = the trial on which the first success occurs, support 1, 2, 3, …
Parameters (Editable via number inputs, sliders, or graph clicks)
Selected: p = 0.3, k = 1
Mean (μ)
E[X] = 1/p
-
Variance (σ²)
Var(X) = (1−p)/p²
-
Standard Deviation (σ)
Std = √variance
-
Second Moment E[X²]
Var + Mean²
-
Skewness (γ₁)
(2−p)/√(1−p)
-
PMF Calculator
P(X = k) = (1−p)^(k−1)·p
-
CDF Calculator
P(X ≤ k) = 1 − (1−p)^k, P(X > k) = (1−p)^k
P(X ≤ k) means the probability that the first success occurs within the first k trials.
P(X ≤ k) + P(X > k) = 1.000000
